Form and Validation

A responsive contact form demo made with HTML, CSS, and vanilla JavaScript. This project fulfils the task brief by including Name, Email, Phone, and Message fields and validates empty fields, email format, phone-number length, and message length.

## Features

- Responsive layout for desktop, tablet, and mobile
- Required Name, Email, Phone, and Message fields
- JavaScript validation with helpful inline error messages
- Accessible labels, focus styles, `aria-invalid`, and a live status region
- Message character counter (500-character limit)
- Success feedback when all fields pass validation
- No server, account, or third-party form service required

## Important demo note

This is a front-end-only internship exercise. Submitting the form validates the entered fields and displays a success message; it does **not** send, save, or transmit the information anywhere.

## Files

- `index.html` — structure and form fields
- `style.css` — responsive styling
- `script.js` — form validation and interactions
